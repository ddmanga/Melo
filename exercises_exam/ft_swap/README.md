# ft_swap

Répertoire : `ex4/`
Fichiers à rendre : `ft_swap.c`
Autorisé : aucune fonction externe (uniquement de l'arithmétique/affectation)

Écrivez une fonction qui échange les valeurs pointées par deux pointeurs
d'entiers.

Prototype : `void ft_swap(int *a, int *b);`

Exemple :

    int x = 4;
    int y = 5;
    ft_swap(&x, &y);
    // x vaut maintenant 5, y vaut maintenant 4
