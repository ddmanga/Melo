# ft_rev_params

Répertoire : `ex8/`
Fichiers à rendre : `ft_rev_params.c`
Autorisé : `write`, `main`

Écrivez un programme qui affiche les arguments passés en ligne de commande
(sans compter le nom du programme), un par ligne, dans l'ordre inverse
(le dernier argument en premier).

Si aucun argument n'est passé, le programme n'affiche rien.

Exemple :

    $> ./a.out un deux trois
    trois
    deux
    un
