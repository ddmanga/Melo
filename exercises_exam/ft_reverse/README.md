# ft_reverse

Répertoire : `ex10/`
Fichiers à rendre : `ft_reverse.c`
Autorisé : aucune fonction externe

Écrivez une fonction qui inverse l'ordre des caractères d'une chaîne de
caractères (la chaîne est modifiée directement en mémoire, sans rien
retourner).

Prototype : `void ft_reverse(char *str);`

Exemple :

    char s[] = "salut";
    ft_reverse(s);
    // s vaut maintenant "tulas"
