# ft_capitalize

Répertoire : `ex11/`
Fichiers à rendre : `ft_capitalize.c`
Autorisé : aucune fonction externe

Écrivez une fonction qui transforme une chaîne de caractères de sorte que
toutes les lettres soient en minuscules, sauf la première lettre qui doit
être en majuscule (la chaîne est modifiée directement en mémoire, sans
rien retourner).

Prototype : `void ft_capitalize(char *str);`

Exemple :

    char s[] = "hELLO WoRLD";
    ft_capitalize(s);
    // s vaut maintenant "Hello world"
