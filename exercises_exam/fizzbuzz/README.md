# ft_fizzbuzz

Répertoire : `ex6/`
Fichiers à rendre : `ft_fizzbuzz.c`
Autorisé : `write`

Écrivez une fonction qui affiche les nombres de 1 à 100, un par ligne,
selon la règle suivante :
- si le nombre est un multiple de 3, affichez "Fizz" à la place du nombre
- si le nombre est un multiple de 5, affichez "Buzz" à la place du nombre
- si le nombre est un multiple de 3 ET de 5, affichez "FizzBuzz" à la place
  du nombre
- sinon, affichez le nombre lui-même

Prototype : `void ft_fizzbuzz(void);`

Exemple (début de la sortie) :

    1
    2
    Fizz
    4
    Buzz
    Fizz
    7
    8
    Fizz
    Buzz
    11
    Fizz
    13
    14
    FizzBuzz
    ...
