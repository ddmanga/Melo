# ft_zero

Répertoire : `ex9/`
Fichiers à rendre : `ft_zero.c`
Autorisé : aucune fonction externe

Écrivez une fonction qui transforme tous les caractères d'une chaîne de
caractères en '0', sur toute la longueur de la chaîne (la chaîne est
modifiée directement en mémoire, sans rien retourner).

Prototype : `void ft_zero(char *str);`

Exemple :

    char s[] = "salut";
    ft_zero(s);
    // s vaut maintenant "00000"
