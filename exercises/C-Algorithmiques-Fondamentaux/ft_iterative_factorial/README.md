ft_iterative_factorial
Répertoire: ex0/
Fichiers à Rendre: ft_iterative_factorial.c
Autorisé: None

- Écrire une fonction itérative qui retourne un entier. Cet entier est le
  résultat de la factorielle du nombre passé en paramètre.
- Si l'argument est invalide, la fonction devra retourner 0.
- Les dépassements de capacité (overflow) ne doivent pas être gérés, le
  comportement est indéfini dans ce cas.

Prototype :
int ft_iterative_factorial(int nb);
