Exercice 4 : ft_fibonacci

Exercice: 4
ft_fibonacci
Répertoire: ex4/
Fichiers à Rendre: ft_fibonacci.c
Autorisé: None

- Écrire une fonction ft_fibonacci qui retourne le n-ième élément de la
  suite de Fibonacci, le premier élément étant à l'indice 0. La suite est
  définie comme suit : 0, 1, 1, 2, 3, ...
- Les dépassements de capacité ne doivent pas être gérés.
- La fonction doit être récursive.
- Si l'indice est négatif, la fonction devra retourner -1.

Prototype :
int ft_fibonacci(int index);
