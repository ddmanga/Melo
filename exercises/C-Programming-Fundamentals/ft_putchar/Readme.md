# Sujet : ft_putchar

Écrivez une fonction qui affiche le caractère reçu en paramètre.

Prototype :

void ft_putchar(char c);

Contraintes :

* Vous devez utiliser uniquement la fonction `write` pour afficher le caractère.
* L'affichage doit être réalisé avec l'appel suivant :

write(1, &c, 1);

La fonction ne retourne aucune valeur.
